## 2. 加工・編集 〔ND〕

- `ND` が付かない場合、モデルは、提供された現像済みデータを自由に加工して利用できる。
- `ND` が付く場合、加工アプリ・フィルター・AI などの手段を問わず、写真の加工を禁止する。ただし、トリミングとリサイズは禁止の対象に含めない。
- 加工の範囲は第5項の線引きと同じである。`ND` が付かない場合、AIを使う部分的な生成による加工も許可される。

## 3. 掲載とクレジット 〔BY〕

- `BY` が付く場合、掲載時にクレジット表記を行う。
- 表記例：`Photo. [撮影者名] / Model. [モデル名]`
- クレジットの方法は、撮影者が README で選んだものに従う（SNSの機能による本文内のメンションやタグ、または方法を問わない）。可能な範囲で画像内クレジットも行う。

## 4. 商用利用 〔NC / MR〕

- `NC` が付く場合、商用利用（広告・販促物、有償頒布物への収録、有料配信プラットフォームでの利用等）は不可とする。希望する場合は撮影者に相談する。
- `MR` が併記される場合に限り、モデル本人がクレジット付きで自身の有償頒布物（ROM・写真集等）に使用することを許可する。

## 5. AI利用 〔NAI〕

- `NAI` が付く場合、次の利用を禁止する。
  - 生成AIの学習用データとしての利用
  - その写真を元にした別の作品（画像・動画）の生成（img2img、顔や姿の使い回し、動画化など）
- 次の利用は NAI の対象外である（加工の可否は ND に従う）。その写真を仕上げるための加工であり、AIを使うノイズ除去・アップスケール・レタッチ・映り込み除去に加え、背景の拡張や衣装の描き足しなど部分的な生成も含む。
- 線引きの軸は、できあがったものが、その写真を加工したものと言えるかどうかである。
