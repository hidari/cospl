# CosPL タグ仕様 v2.0

利用条件はタグの組み合わせで表します。

## 文書の構造

CosPL の文書は 2 層でできています。

- 本体：タグで決まる共通の条件。識別子と AI 向け宣言に反映されます。
- 拡張：撮影者が見出しと項目を自由に書き足す追加事項。内容物や書き出しサイズ、撮影者側の利用など、撮影者ごとの運用を書きます。

優先順位は本体が上です。拡張は本文書への追加であり、本体の条件と矛盾する場合は本体の条件が優先します。拡張でできるのは、細かいお願いを足すことと、本体より厳しくすることだけです。本体の禁止を拡張で緩めることはできません（本体の条件はモデルの肖像権も守っており、撮影者が一方的に外せてはならないため）。

## 識別子の書式

```
CosPL <バージョン> / <タグをハイフンで連結>
CosPL <バージョン> / <タグをハイフンで連結> +
```

拡張が 1 つ以上あるとき、末尾に ` +` を付けます。` +` は内容ではなく「本体以外の条件がある」ことだけを示します。

例：

```
CosPL 2.0 / BY-NC-NAI-TD
CosPL 2.0 / BY-NC-NAI-TD +
CosPL 2.0 / BY-NC-ND-NAI-TD-SB-MR
```

タグは集合です。順序に意味はなく、`MR-SB-ND-BY` と `BY-ND-SB-MR` は同じ条件を表します。定義順 `BY, NC, ND, NAI, TD, SB, MR` は表示の正規形にすぎず、表記するときはこの順に並べます。

## コアタグ

| タグ    | 名称                   | 内容                                              |
|-------|----------------------|-------------------------------------------------|
| `BY`  | Attribution（クレジット表記） | 掲載時にクレジット表記が必要                                  |
| `NC`  | NonCommercial（非商用）   | 商用利用は不可。希望する場合は要相談                              |
| `NAI` | No-AI（AI不可）          | 生成AIの学習用データとしての利用と、その写真を元にした別の画像・動画の生成を禁止       |
| `TD`  | Takedown（取り下げ可）      | 公開後の取り下げ依頼に撮影者・モデル双方が応じる                        |

`BY` と `NC` は Creative Commons の同名タグと同じ趣旨です。CosPL 独自のタグは `NAI`、`TD`、`SB` です。`ND` は Creative Commons の `ND` を下敷きにしていますが、トリミングとリサイズを許可する点が異なります。

### ND の範囲

`ND` が付く場合は加工を禁止しますが、SNS への投稿時の切り抜きや縮小を想定して、トリミングとリサイズは許可します。`ND` が付かない場合は自由に加工できます。色の調整はしないでなど細かい希望は、拡張で足します。

### NAI の線引き

- 禁止：学習データとしての利用と、写真を元に別の作品（画像・動画）を生成すること（img2img、顔や姿の使い回し、動画化など）
- 許可：その写真を仕上げるための加工。AIを使うノイズ除去・アップスケール・レタッチ・映り込み除去に加え、背景の拡張や衣装の描き足しなど部分的な生成も含む
- 判断の軸：できあがったものが、その写真を加工したものと言えるか

`ND` と `NAI` の加工の範囲はそろえてあります。`ND` が付かなければ、AIを使う部分的な生成による加工も加工として許可されます。

## オプションタグ

| タグ   | 名称                     | 内容                                         |
|------|------------------------|--------------------------------------------|
| `ND` | NoDerivatives（加工禁止）      | 写真の加工を禁止。ただしトリミングとリサイズは許可                  |
| `SB` | SendBack（データバック）       | 掲載のため、撮影者へ写真の返送を依頼する                       |
| `MR` | Model-ROM（モデル本人の有償頒布可） | モデル本人がクレジット付きで自身の有償頒布物（ROM・写真集等）に使用することを許可 |

`NC`（非商用）を付けつつ `MR` を併記すると、「商用は原則不可だが、モデル本人の有償頒布だけは許可」という意味になります。

## 版の運用

版の運用は Creative Commons に準拠します。

- 条件の中身が変わるときだけ新しい版を出します。既存タグの意味の変更、タグの廃止や改名、識別子の書式の変更、許諾の構造の変更はメジャー版、任意のタグや仕組みの追加とあいまいな文言の解消はマイナー版です。
- パッチ版は作りません。誤字や言い回しは版を変えずにその場で直します。
- 古い版は公開したまま有効です。自動では新しい版に移らず、どの版を使うかは書いた本人が選びます。

## 注意

- タグはあくまで条件の要約です。実際の許諾内容は本文（CosPL-2.0.md）およびテンプレートの記載が優先します。
- 新しいタグを独自に追加した場合は、その定義を併記してください。
